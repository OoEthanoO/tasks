# Expo SDK 54

This project is pinned to **Expo SDK 54**, not the newest SDK. The version that
matters is the one the App Store's Expo Go reports under Settings → App Info →
Supported SDK; npm's `latest` runs ahead of it, and a project on a higher SDK
simply refuses to open in Expo Go.

Read the versioned docs at https://docs.expo.dev/versions/v54.0.0/ before
writing any code. Before bumping `expo` in package.json, check the phone.

## Layout notes

- Shared logic lives in `../lib` and is imported by relative path. It is the
  same code the Next.js web app runs — do not fork it.
- `metro.config.js` sets `watchFolders` only. Do not add `nodeModulesPaths` or
  `disableHierarchicalLookup`: several of expo's own dependencies sit nested in
  `node_modules/expo`, and those options hide them.
- The app icon is generated by `assets/generate-icon.py`. Edit the script, not
  the PNGs.
